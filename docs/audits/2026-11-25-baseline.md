## Findings

- **Code and logic:** scaffold only: an app shell, a lazy home page and `src/app/core/time-spent.ts` (time on site, duration format) with tests. Angular 22's generated `tsconfig.json` lacks `"strict": true`; added with `strictTemplates` (AGENTS, "Known pitfalls").
- **Tests:** unit tests only; no browser suite yet, so the template's `e2e` job is removed from CI until one exists.
- **Documentation:** README, AGENTS, areas, style guide and backlog docs written for Hobo; `docs/DESIGN.md` starts with F-002-T01.
- **Security and privacy:** no secrets; `public/config.local.json` and `.env` are git-ignored for provider keys; the owner's places and photos stay out of git (AGENTS, "Privacy").
- **Delivery:** no deployment; the app runs locally. CI runs on the first PR. Branch protection and auto-merge are owner settings (F-001-T02).
- **Backlog:** the full feature plan is recorded up front: F-001 to F-014, 36 steps with estimates.
